## Transmog

Transmog — Copyright (c) 2023 Hidoni. The upstream MIT license is retained in `LICENSES/Transmog-MIT.txt`.

Source: https://github.com/Hidoni/Transmog

The original MOD credits **elinka47** for its existing Japanese translation. This unofficial pack provides 25 independently reviewed Japanese strings based on Transmog 1.8.0+26.1. Source: https://github.com/mezz/JustEnoughItems/tree/634d109ddd299a62beb2d9a1b8566da3dfd56bb8

Target: JEI 29.36.0.96 for Minecraft 26.1.2 / NeoForge. The upstream English and Japanese assets in this version match tag `v29.36.0`, commit `634d109ddd299a62beb2d9a1b8566da3dfd56bb8`.

Existing Japanese contributors include **Abbage230**, whose 26.1 update was merged in [upstream PR #4300](https://github.com/mezz/JustEnoughItems/pull/4300). This is not an exhaustive list of historical contributors.

Version 0.2.0 includes 334 independently reviewed Japanese display strings and one unchanged metadata entry, recorded in `release.json` and `reviews/jei.json`. JEI uses normal language overrides; no JEI resource is blocked. The non-display `_comment` metadata, if present, retains its original English value and is excluded from the display-string count.

## Scope

This is an unofficial Japanese improvement pack, not an official release by the original authors or translators. ATM11 quest definitions, unrelated MOD translations, MOD JARs, worlds, logs, and installation backups are not included. The independent review summaries identify the source, accepted keys, reviewer and hashes; they are provenance records, not digital signatures or proof of visual game testing.
