## Changes / 改変内容

Version 0.3.0 includes Japanese values for **496 current English keys**, including narration and search keywords. The original Japanese language is revised and missing current keys are supplied. Existing original translator credits are retained. `jade.metadata` preserves the exact original Japanese runtime language settings; `__comment` retains the original English testing-section marker. These two preserved entries are not new translations.

本パックは日本語の名称・説明・ナレーション・検索補助語などを改変します。元の日本語の翻訳者表示と言語機能設定を保持します。496 は metadata を含むキー数であり、画面数や全件の実表示確認を示しません。

The pack uses ordinary key overlays with **no resource filter**. It does not contain or alter the MOD JAR. Existing Japanese-only upstream keys can remain in lower-priority resources. No quests, worlds, private logs or backups are distributed.

## Review provenance

`release.json` binds the language bytes and `reviews/jade.json`. The review summary records the exact source/JAR hashes, accepted keys, reviewer and original review/submission hashes. These are provenance records, not digital signatures or a claim of complete visual game testing. Only independently accepted inputs can pass the builder.
